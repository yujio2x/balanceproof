FAQ


      

        Do my files really stay on my computer?
        
Yes. BalanceProof is a static web app: the PDF is read and parsed by JavaScript running in your browser tab. There is no server to upload to. And because the whole tool is open source (MIT), you don't have to take our word for it — the code that handles your statement is public. After the page loads you can even go offline and keep converting.

      


      

        Which banks are supported?
        
BalanceProof parses common US (MM/DD/YYYY) and UK (DD/MM/YYYY) statement and card layouts, rather than one hardcoded list of banks. Every statement with a running-balance column is checked mathematically: if the parsed rows reconstruct the balance to the penny, you see a green “reconciles” badge; if not, the wrong rows are highlighted. Coverage grows from user reports — if your bank's layout reads wrong, report it and it gets fixed.

      


      

        My PDF is a scan / photo. Does it work?
        
No — scanned statements are images with no text to extract, and running OCR would require a server, which would break the privacy model. Text-based PDFs downloaded from online banking work. If your bank only sends scans, ask them for a digital statement export, or try your bank's website — most offer PDF downloads with selectable text.

      


      

        How do I import into QuickBooks or Xero?
        
QuickBooks Desktop: export .qbo, then File → Import → Bank transactions; QuickBooks will ask you to map it to your account the first time. QuickBooks Online: use the Pro "QuickBooks CSV" export and import via Banking → File upload. Xero: use the Pro Xero CSV and import via Accounting → Bank accounts → Import a statement.

      


      

        Why does it sometimes flag rows as not reconciling?
        
Some banks print debits as plain positive numbers; BalanceProof auto-detects this, but unusual layouts can still slip through. Other causes: two-character OCR-style typos in the PDF text layer, or transactions that continue on the next page. The flagged rows are highlighted so you can fix or delete them before exporting.
